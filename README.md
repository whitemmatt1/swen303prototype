# Transit App Prototype

A modern, user-friendly transit application built with Next.js, React, and TypeScript. This prototype application provides a comprehensive solution for public transportation users, offering features for trip planning, real-time tracking, and accessibility options.

## Features

### Trip Planning
- Plan trips with real-time route suggestions
- Multiple route options (fastest, cheapest, wheelchair-accessible)
- Save and manage favorite trips
- View trip details including fare, ETA, and transfer information

### User Experience
- Modern, responsive UI built with Tailwind CSS
- Dark/light mode support
- Bottom navigation for easy access to key features
- Toast notifications for important updates

### Accessibility Features
- Peaceful mode for reduced visual stimulation
- Low-floor vehicle preferences
- Wheelchair space requirements
- High contrast mode
- Vibration alerts
- Customizable notification settings

### Trip Management
- Save and organize frequent trips
- Active trip tracking with progress updates
- Edit and delete saved trips
- Restore deleted trips
- View trip history

### Additional Features
- Real-time arrival notifications
- Delay alerts
- Fare information
- Location-based suggestions
- Settings management
- Ticket purchasing options

## Technical Stack

- **Framework**: Next.js 15.2.4
- **Language**: TypeScript
- **UI Components**: Radix UI
- **Styling**: Tailwind CSS
- **State Management**: React Hooks
- **Form Handling**: React Hook Form
- **Validation**: Zod
- **Icons**: Lucide React
- **Charts**: Recharts
- **Date Handling**: date-fns

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   # or
   pnpm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   # or
   pnpm dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Development

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run linting

## Note

This is a prototype application and may not include all features in a production environment. The application is designed to demonstrate the user interface and core functionality of a modern transit application.
